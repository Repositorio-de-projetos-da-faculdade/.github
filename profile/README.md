## Em destaque

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="seamoney-logo-on-dark.svg">
  <img src="seamoney-logo-on-light.svg" alt="Seamoney" height="44">
</picture>

> Pagamentos internacionais mais simples, baratos e com conciliação automática.

Importadoras brasileiras pagam fornecedores na Ásia com stablecoins. O sistema calcula o custo da operação, lê a fatura, envia o pagamento com o código da ordem no memo da transação, concilia sozinho na rede e gera a página de prova para o fornecedor, além do relatório em CSV.

- **Site:** [seamoney.tech](https://seamoney.tech)
- **Aplicativo:** [app.seamoney.tech](https://app.seamoney.tech) (contas de teste na própria tela de entrada)
- **Redes:** testnet do Tempo e devnet da Solana. A conversão de reais para dólar é **simulada** e nenhum dinheiro real é movimentado.
- **Tecnologias:** Next.js · Java e Spring Boot · Python e FastAPI · PostgreSQL · Docker
- **Origem:** feito para o hackathon Crypto World's Fair (Colosseum), trilha Tempo.

## English

**Featured: Seamoney** — international payments made simpler and cheaper, with automatic reconciliation. Brazilian importers pay suppliers in Asia with stablecoins; the system quotes the cost, reads the invoice, sends the payment with the order code in the transaction memo, reconciles it on-chain by itself and produces a proof page for the supplier. It runs on the Tempo testnet and Solana devnet: the BRL-to-USD leg is **simulated** and no real money moves. Built for the Crypto World's Fair hackathon (Colosseum), Tempo track. [seamoney.tech](https://seamoney.tech) · [app.seamoney.tech](https://app.seamoney.tech)

**Also here:** [RoundLog](https://github.com/Repositorio-de-projetos-da-faculdade/roundlog-api), a smart ward-round record with AI-processed audio, nursing dashboard and family portal; and [NexusDoc](https://github.com/Repositorio-de-projetos-da-faculdade/nexusDoc-api), smart contract management with AI extraction and semantic search.
